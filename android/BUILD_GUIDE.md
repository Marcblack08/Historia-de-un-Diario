# Android Build

## Desarrollo
1. Abrir en Godot 4.x.
2. Instalar/configurar Android SDK y JDK.
3. Configurar el preset Android.
4. Probar APK en dispositivo.

## Release
- Usar keystore de release.
- Generar AAB para Google Play.
- Nunca subir secretos o keystores al repositorio.

## GitHub Actions
El workflow se añadirá cuando el proyecto Godot base esté validado localmente para evitar automatizar una exportación rota.
