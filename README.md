# Historia de un Diario

Videojuego de terror en primera persona para Android y PC.

## Objetivo
Construir el Capítulo 1 con exploración, linterna, interacción, diario, puzles, eventos de terror y enemigo.

## Tecnología
- Godot 4.x
- Android ARM64
- GitHub Actions
- APK para pruebas
- AAB para distribución

## Estructura
- `scenes/` escenas del juego
- `scripts/` lógica
- `assets/` modelos, texturas y materiales
- `audio/` sonidos y música
- `ui/` interfaz
- `android/` documentación/configuración Android
- `docs/` diseño y producción

## Flujo
`develop` para desarrollo -> `main` para estable.
