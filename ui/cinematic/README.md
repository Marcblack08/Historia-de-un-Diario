# Cinemáticas fotográficas

Coloca aquí las fotografías cinematográficas de alta calidad usadas por la introducción.

Archivos esperados:

- `arrival_01.jpg` — vista desde el automóvil hacia la casa.
- `arrival_02.jpg` — avance por el camino mojado.
- `arrival_03.jpg` — fachada y puerta bajo la lluvia.
- `arrival_04.jpg` — ventana o detalle inquietante.

La introducción aplica automáticamente zoom lento, paneo y fundidos. Si una foto falta, utiliza temporalmente `ui/main_menu_cinematic_github.jpg` como respaldo.
